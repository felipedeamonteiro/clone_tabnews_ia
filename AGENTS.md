# AGENTS.md

## Sobre o projeto

Clone do [TabNews](https://www.tabnews.com.br) (do Filipe Deschamps) desenvolvido para o **curso.dev**, utilizando agentes de IA.

## Stack

- **Next.js 16** (App Router)
- **React 19**
- JavaScript puro (sem TypeScript)
- CSS puro (sem framework de CSS)

## Comandos

```bash
npm run dev    # servidor de desenvolvimento
npm run build  # build de produção
npm run start  # sobe o build de produção
```

## Convenções

- Idioma do conteúdo e dos nomes no código: português.
- `node_modules` e `.next` estão no `.gitignore`.
